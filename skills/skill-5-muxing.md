# Skill 5: 多轨道封装批处理生成器

## 技能描述

通过对话引导用户导入多个视频、音频、字幕、字体文件，生成 ffmpeg 多轨道封装命令，输出为 `ffmpeg_mux.bat` 批处理文件。

## 触发条件

用户提出以下意图之一：
- 封装/混流视频
- 合并音视频轨道
- 生成封装批处理
- 创建 mux 命令

## 对话流程

### 第一步：导入工具与路径

依次请求用户提供：

```
（1/4）导入 ffprobe.exe 路径
（2/4）导入 ffmpeg.exe 路径
（3/4）选择导出封装批处理的文件夹
（4/4）选择封装结果的导出文件夹
```

### 第二步：循环导入素材文件

**提示用户：**
> 仅第一个视频文件会被用作主视频流，后续文件只添加音频、字幕等轨道。

**循环流程：**

1. **请求用户提供第 N 个源文件路径**

2. **根据文件类型分析流：**

#### 视频容器格式（.mkv/.mp4/.mov/.f4v/.flv/.avi/.m3u/.mxv）

执行 ffprobe 检测所有流：

```bash
ffprobe -v quiet -print_format json -show_streams -select_streams v "{文件}"
ffprobe -v quiet -print_format json -show_streams -select_streams a "{文件}"
ffprobe -v quiet -print_format json -show_streams -select_streams s "{文件}"
```

- 视频流：仅保留第一个，获取帧率信息
  - 参数: `-r {帧率} -c:v copy`
- 音频流：如果存在，参数: `-c:a copy`
- 字幕流：如果存在，参数: `-c:s copy`

#### 音频容器格式（.m4a/.mka/.mks）

- 音频流：`-c:a copy`
- 字幕流（如果有）：`-c:s copy`

#### 单文件格式（未封装的视频/音频/字幕/字体）

**视频文件（无有效帧率时需要交互）：**

如果文件自带有效帧率：直接使用。

如果无有效帧率，向用户展示选项：

```
选择帧率来源：
1：手动输入帧率
2：从其他封装视频文件读取（推荐）
3：使用常用预设帧率
q：跳过此文件
```

**选项 1 - 手动输入：**
> 请输入帧率（整数/小数/分数，如 24、23.976、24000/1001）

**选项 2 - 从文件读取：**
> 选择一个包含帧率信息的封装视频文件
> 使用 ffprobe 提取帧率

**选项 3 - 预设帧率：**

```
常用帧率预设：
1. 23.976（24000/1001）
2. 24
3. 25
4. 29.97（30000/1001）
5. 30
6. 48
7. 50
8. 59.94（60000/1001）
9. 60
a. 120
b. 144
```

**音频文件：** `-c:a copy`
**字幕文件（.srt/.ass/.ssa）：** `-c:s copy`
**字体文件（.ttf/.ttc/.otf）：** `-c:t copy`

3. **累积映射参数：**
   ```
   -i "文件1" -i "文件2" ...
   -map 0 {args0} -map 1 {args1} ...
   ```

4. **询问是否继续：**
   ```
   继续添加文件？输入 'y' 确认，按 Enter 完成
   ```

### 第三步：确定输出文件名

```
请输入输出文件名（留空默认：{源文件名}_mux）
```

验证文件名合法性。

### 第四步：选择封装容器

```
选择封装容器:
1：MP4（适合通用）
2：MOV（适合剪辑）
3：MKV（兼容字幕、字体）
4：MXF（专业用途）
⚠️ ffmpeg 正在弃用 MP4 时间码（pts）生成功能，届时 MP4 格式选项将不可用
```

### 第五步：兼容性检查与自动修复

#### 检查 1：字体流 + MP4/MOV/MXF

如果命令中包含 `-c:t copy` 且容器为 MP4/MOV/MXF：

```
⚠️ 检测到字体流（-c:t copy），但 MP4/MOV/MXF 不支持
请选择一个选项继续：
d：删除导入语句
m：将容器格式更改为 MKV
Enter：忽略
```

#### 检查 2：字幕流 + MP4/MOV

如果命令中包含 `-c:s copy` 且容器为 MP4/MOV：

```
⚠️ 检测到字幕流（-c:s copy），MP4/MOV 支持较差，大概率无法封装
请选择一个选项继续：
d：删除导入语句
m：将容器格式更改为 MKV
Enter：忽略
```

### 第六步：生成批处理文件

**构建 ffmpeg 命令：**
```
"{ffmpeg路径}" {所有-i参数} {所有-map和编解码参数} "{输出路径/文件名.容器}"
```

**批处理模板：**

```batch

@echo off
chcp 65001 >nul
setlocal

REM ========================================
REM ffmpeg 封装工具
REM 生成时间：{当前时间}
REM ========================================

echo.
echo 开始封装任务...
echo.

{ffmpeg命令}

echo.
echo ========================================
echo  批处理执行完毕！
echo ========================================
echo.

endlocal
echo 按任意键进入命令提示符，输入 exit 退出...
cmd /k
```

### 第七步：保存与提示

1. UTF-8 BOM 编码、CRLF 换行符写入
2. 保存为 `ffmpeg_mux.bat`
3. 提示：
   ```
   命令已保存至：{路径}
   提示：如果音画不同步，请在 -map 和 -c 之间添加 -itoffset <秒> 参数
   ```

## 帧率验证规则

有效帧率格式：
- 分数: `24000/1001`
- 整数: `24`
- 小数: `23.976`
- 排除: `0/0`、`0`、`0.0`

## 输出

| 文件 | 位置 | 用途 |
|------|------|------|
| ffmpeg_mux.bat | 用户指定的导出目录 | ffmpeg 多轨道封装命令 |

## 依赖

- ffprobe 可执行文件
- ffmpeg 可执行文件
- 此技能独立于 Skill 1-4，可单独使用
